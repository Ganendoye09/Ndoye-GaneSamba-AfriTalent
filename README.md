# AfriTalent 🌍

Plateforme fictive de mise en relation entre freelances tech africains et entreprises du monde entier.

- **Nom :** GaneSamba Ndoye
- **Classe :** L1 Web — ISI
- **Année :** 2025-2026

---

## 📝 Description

AfriTalent est un site vitrine complet développé dans le cadre du projet fil rouge du Semestre 2.
Il présente une plateforme fictive permettant aux freelances africains de proposer leurs services
et aux entreprises de trouver les talents dont elles ont besoin.

Le site reflète les tendances web de 2026 : design épuré, typographie expressive, mise en page
en Bento Grid, accessibilité et interactivité JavaScript.

---

## 🛠️ Technologies utilisées

- **HTML5** — Structure sémantique rigoureuse
- **CSS3** — Flexbox, Grid, Bento Grid, animations, variables CSS, responsive design
- **Bootstrap 5** — Grille, navbar, cards, carousel, accordion
- **JavaScript (Vanilla)** — DOM, événements, IntersectionObserver, localStorage
- **Google Fonts** — Bebas Neue, IBM Plex Sans JP, Roboto
- **Font Awesome** — Icônes
- **Git & GitHub** — Versioning et déploiement GitHub Pages

---

## ✨ Fonctionnalités principales

- 🌙 Dark Mode / Light Mode avec persistance (localStorage)
- 🔢 Compteurs animés au scroll (IntersectionObserver)
- 👁️ Animations fade-in des sections au scroll
- 🔍 Filtrage dynamique des freelances par catégorie
- ✅ Validation complète du formulaire de contact
- 📜 Navbar dynamique au scroll
- ⬆️ Bouton retour en haut
- 📱 Responsive design (mobile, tablette, desktop)

## 🚀 Lancer le projet localement

1. Clone le dépôt :
```bash
git clone https://github.com/Ganendoye09/Ndoye-GaneSamba-AfriTalent.git
```

2. Ouvre le dossier dans VS Code

3. Installe l'extension **Live Server**

4. Clic droit sur `index.html` → **Open with Live Server**
